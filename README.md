One word for the whole internet: **Doomscroll**.

The internet, in one word, is the thing everyone does on it at 2 a.m. when they meant to check one thing: keep scrolling through an endless feed of bad news, outrage and oddly compelling nonsense, unable to stop. "Doom" names the dread the feed runs on, "scroll" names the motion. The program in `main.ts` writes that single word (10 characters) to `entry.txt` in the output directory, after checking it really is one plain word of letters only, 1 to 30 characters.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
